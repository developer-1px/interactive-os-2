# Visual CMS 와이어프레임

## 1. 기본 편집 화면

```
+------------------+-------------------------------+------------------+
|    Sidebar       |          Canvas               |   Detail Panel   |
|    (280px)       |          (flex-1)             |    (320px)       |
|                  |                               |                  |
|  [TreeView]      |  [Workspace]                  |  [Form]          |
|                  |                               |                  |
|  - Page          |  +-------------------------+  |  노드 타입: Text  |
|    - Hero        |  |                         |  |  ────────────    |
|    - Section     |  |   선택된 노드가          |  |  내용: [TextInput]|
|      - Text  *   |  |   하이라이트 표시        |  |  정렬: [RadioGrp]|
|      - Image     |  |                         |  |  크기: [Slider]  |
|    - Footer      |  +-------------------------+  |                  |
|                  |                               |  [ButtonToolbar] |
|  [ButtonToolbar] |  ─── Floating Toolbar ───     |  저장 | 삭제     |
|  + 노드 추가     |  [Toolbar] 이동|복제|삭제     |                  |
+------------------+-------------------------------+------------------+
|                    [Breadcrumb] Page > Section > Text               |
+--------------------------------------------------------------------+
```

### 영역-부품 매핑

| 영역 | ui/ 부품 | 역할 |
|------|----------|------|
| Sidebar | `TreeView` | cmsStore 노드 트리 탐색/선택 |
| Sidebar 하단 | `ButtonToolbar` | 노드 추가/삭제 액션 |
| Canvas | `Workspace` | 노드 시각 배치, 드래그 이동 |
| Floating Toolbar | `Toolbar` | 선택 노드 조작 (이동/복제/삭제) |
| Detail Panel | `Form` + `TextInput` + `RadioGroup` + `Slider` | 노드 속성 편집 |
| Detail 하단 | `ButtonToolbar` | 저장/삭제 확인 |
| 하단 바 | `Breadcrumb` | 현재 선택 경로 표시 |

## 2. 노드 선택 화면

```
+------------------+-------------------------------+------------------+
|    Sidebar       |          Canvas               |   Detail Panel   |
|                  |                               |                  |
|  [TreeView]      |  [Workspace]                  |  [TabGroup]      |
|                  |  +- - - - - - - - - - - - +  |  스타일 | 데이터  |
|  - Page          |  |  +---------+           |  |  ────────────    |
|    - Hero        |  |  | Image   | [selected]|  |  [Form]          |
|    - Section     |  |  | ███████ |           |  |  src: [TextInput]|
|      - Text      |  |  +---------+           |  |  alt: [TextInput]|
|      - Image *   |  |                        |  |  w: [Spinbutton] |
|    - Footer      |  +- - - - - - - - - - - - +  |  h: [Spinbutton] |
|                  |                               |                  |
|                  |  [SelectionOverlay]            |                  |
|                  |  리사이즈 핸들 + 바운딩 박스    |                  |
+------------------+-------------------------------+------------------+
```

### 영역-부품 매핑 (추가)

| 영역 | ui/ 부품 | 역할 |
|------|----------|------|
| Canvas 오버레이 | `SelectionOverlay` | 선택 노드 바운딩 박스 + 리사이즈 |
| Detail 탭 | `TabGroup` | 스타일/데이터 탭 전환 |
| 크기 입력 | `Spinbutton` | 숫자값 증감 입력 |

## 3. 미리보기 모드

```
+--------------------------------------------------------------------+
|  [Toolbar]  편집 모드 | [미리보기 *] | 반응형: 데스크탑 | 태블릿 | 모바일  |
+--------------------------------------------------------------------+
|                                                                    |
|                     [Workspace]                                    |
|                     (읽기 전용, 전체 너비)                           |
|                                                                    |
|     +------------------------------------------------------+      |
|     |                                                      |      |
|     |              실제 렌더링 결과                          |      |
|     |              인터랙션 비활성                            |      |
|     |                                                      |      |
|     +------------------------------------------------------+      |
|                                                                    |
+--------------------------------------------------------------------+
|  [Breadcrumb] 미리보기 > 데스크탑                                    |
+--------------------------------------------------------------------+
```

### 영역-부품 매핑

| 영역 | ui/ 부품 | 역할 |
|------|----------|------|
| 상단 바 | `Toolbar` + `ToggleGroup` | 모드 전환 + 반응형 뷰포트 선택 |
| 전체 영역 | `Workspace` (readonly) | 편집 불가 프리뷰 |

## 인터랙션 매트릭스

| 사용자 액션 | TreeView | Workspace | Toolbar | Detail Panel |
|------------|----------|-----------|---------|-------------|
| 트리 노드 클릭 | 포커스 이동 + 선택 | 해당 노드 스크롤 + 하이라이트 | 선택 노드 기준 활성화 | 속성 폼 갱신 |
| 캔버스 노드 클릭 | 트리에서 해당 노드 선택 | SelectionOverlay 표시 | 선택 노드 기준 활성화 | 속성 폼 갱신 |
| `Delete` 키 | 선택 노드 삭제 (확인 Dialog) | - | - | 폼 초기화 |
| `Ctrl+D` 복제 | 트리에 복제 노드 추가 | 캔버스에 복제 표시 | - | 복제 노드 속성 표시 |
| 드래그 (캔버스) | 트리 순서 동기화 | 노드 위치 이동 | - | 좌표값 갱신 |
| 드래그 (트리) | 트리 순서 변경 | 캔버스 배치 동기화 | - | - |
| 속성 편집 | - | 실시간 반영 | - | 폼 값 변경 |
| 미리보기 토글 | Sidebar 숨김 | 전체 너비 + 읽기 전용 | 모드 표시 변경 | Panel 숨김 |
| `Escape` | 선택 해제 | 오버레이 제거 | 비활성화 | 폼 초기화 |
