# User Story Map — Visual CMS

> Backbone: 사용자 활동 흐름 (좌→우)
> Walking Skeleton: 각 활동의 최소 동작 단위
> Stories: 우선순위별 사용자 스토리 (P0=MVP, P1=v1, P2=후순위)

---

## 1. 페이지 관리

**Walking Skeleton**: 페이지 생성 → 목록 확인 → 순서 변경

| 우선순위 | 스토리 |
|----------|--------|
| P0 | 빈 페이지를 추가할 수 있다 |
| P0 | 페이지 목록에서 선택하여 이동할 수 있다 |
| P0 | 페이지를 삭제할 수 있다 (Undo 가능) |
| P1 | 드래그앤드롭으로 페이지 순서를 변경할 수 있다 |
| P1 | 페이지를 복제할 수 있다 |
| P2 | 페이지에 이름/태그를 붙여 관리할 수 있다 |

---

## 2. 콘텐츠 편집

**Walking Skeleton**: 노드 추가 → 텍스트 입력 → 노드 삭제

| 우선순위 | 스토리 |
|----------|--------|
| P0 | text 노드를 추가하고 내용을 입력할 수 있다 |
| P0 | badge, icon, cta 등 15개 노드 타입을 삽입할 수 있다 |
| P0 | 노드를 선택하여 속성(value, role 등)을 편집할 수 있다 |
| P0 | Undo/Redo로 편집을 되돌릴 수 있다 |
| P1 | 노드를 드래그앤드롭으로 재배치할 수 있다 |
| P1 | 복수 노드를 선택하여 일괄 삭제/복사할 수 있다 |
| P1 | stat, step 등 컨테이너 노드에 자식을 추가할 수 있다 |
| P2 | 클립보드로 노드를 복사/붙여넣기할 수 있다 |
| P2 | 다국어(ko/en/ja) 필드를 전환하며 편집할 수 있다 |

---

## 3. 디자인 조정

**Walking Skeleton**: 레이아웃 선택 → 색상 변경 → 간격 조정

| 우선순위 | 스토리 |
|----------|--------|
| P0 | 페이지의 레이아웃 템플릿을 선택할 수 있다 |
| P1 | 노드의 시각 스타일(색상, 크기)을 변경할 수 있다 |
| P1 | section/card 등 구조 노드의 배치를 조정할 수 있다 |
| P2 | 커스텀 테마를 적용할 수 있다 |
| P2 | 반응형 뷰포트별 레이아웃을 미리볼 수 있다 |

---

## 4. 미리보기/배포

**Walking Skeleton**: 전체 미리보기 → 공유 링크 생성

| 우선순위 | 스토리 |
|----------|--------|
| P0 | 슬라이드쇼 형태로 전체 페이지를 미리볼 수 있다 |
| P1 | 공유 가능한 뷰어 링크를 생성할 수 있다 |
| P1 | 뷰어에서 키보드로 페이지를 탐색할 수 있다 |
| P2 | PDF/이미지로 내보낼 수 있다 |
| P2 | 버전 히스토리를 확인하고 복원할 수 있다 |

---

## Release 매핑

| Release | 범위 |
|---------|------|
| **MVP (P0)** | 페이지 CRUD + 15 노드 편집 + Undo/Redo + 미리보기 |
| **v1 (P1)** | DnD 재배치 + 일괄 편집 + 디자인 조정 + 공유 링크 |
| **v2 (P2)** | 다국어 + 테마 + 내보내기 + 버전 관리 |
